Smart AI-Powered Digital Tourism Platform (Jharkhand)

Monorepo with Vite React frontend and Express backend.

Quick start

Prerequisites
- Node.js (recommended: Node 22.12.0 or Node 20.19.0 LTS or newer)
- npm (bundled with Node)

1) Backend
   - cd backend
   - copy `.env.example` to `.env` and set secrets (create the file if missing)
   - npm install
   - npm run dev

2) Frontend
   - Ensure Node is upgraded to >= 20.19.0 or >= 22.12.0 (see notes below)
   - cd frontend
   - npm install
   - npm run dev

Health check
- Backend: http://localhost:5000/api/health

Notes on Node version
- Vite requires Node >= 20.19.0 or >= 22.12.0. If you have Node 22.11.x you will see an error telling you to upgrade.

Recommended Node installation methods (pick one)

1) nvm-windows (recommended)
- Install from: https://github.com/coreybutler/nvm-windows/releases (run installer)
- Example commands after installing nvm:

```powershell
nvm install 22.12.0
nvm use 22.12.0
node -v
```

2) Official Node installer
- Download Node 22.12.0 (or Node 20.x LTS >= 20.19.0) from https://nodejs.org/ and run the installer.

Troubleshooting
- If Vite fails due to Node version, upgrade Node.
- If ports conflict, stop the process using the port or use a different port. Set backend `PORT` env or run Vite with `--port`.
- If frontend reports socket/proxy connection refused, make sure backend is running and reachable at http://localhost:5000.
